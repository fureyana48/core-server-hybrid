# Repository Template

Recommended lifecycle:

`DISCOVERY → BASELINE → IMPLEMENTATION → VALIDATION → BACKUP → RELEASE → FREEZE → UPPER-LAYER DEVELOPMENT`

Every infrastructure project should document:
1. Scope
2. Platform
3. Software baseline
4. Dependencies
5. Configuration
6. Implementation
7. Validation criteria
8. Artifact location
9. Recovery procedure
10. Release status
11. Known limitations
12. Change history
